# 查證清單工具（/review）部署設定

給「查證清單工具」頁面用的 Google Apps Script 部署步驟，跟著做一次就好，之後同步功能就會一直可以用。

## 這個工具在做什麼

- 網址：`https://ingredient-guide-app.web.app/review`
- 開啟頁面時會自動連線讀取試算表最新狀態，所以不管在手機還是電腦打開，看到的都是最新的核對進度
- 貼上 `docs/VERIFICATION_TODO.md` 的內容 → 解析成一筆一筆的待查證項目（同時自動上傳到試算表的「項目清單」分頁，讓其他裝置也讀得到）
- 打勾＋寫備註都先存在瀏覽器本機（沒網路也能用），按「同步到試算表」才會把異動推到試算表的「查證紀錄」分頁
- 如果某台裝置打勾後還沒按同步，其他裝置重新載入時不會蓋掉那筆還沒同步的紀錄，等按下同步才會生效

## 第一步：建立試算表並貼上程式碼

1. 到 [Google 試算表](https://sheets.google.com) 開一個新的空白試算表，取個名字（例如「食材圖鑑查證紀錄」）
2. 上方選單點「擴充功能」→「Apps Script」，會開一個新分頁的程式碼編輯器
3. 把編輯器裡預設的 `function myFunction() {...}` 全部刪掉，貼上 [`docs/apps-script-review-sync.gs`](apps-script-review-sync.gs) 的完整內容
4. 上方點「儲存專案」（磁片圖示），專案名稱隨便取，例如「查證同步」

## 第二步：設定通關密語

這一步是把密語存在 Apps Script 專案自己的設定裡，不會出現在程式碼裡：

1. 在 Apps Script 編輯器左側，點齒輪圖示「專案設定」
2. 往下捲到「指令碼屬性」，點「新增指令碼屬性」
3. 屬性名稱填：`SYNC_SECRET`
4. 值填：
   ```
   TTteVRRqRZC18o4tVgxGcMot4R9qmSE2
   ```
5. 點「儲存指令碼屬性」

## 第三步：部署成網頁應用程式

1. 回到左側「編輯器」（左上角 `<>` 圖示），右上角點藍色「部署」按鈕 → 「新增部署作業」
2. 左邊齒輪圖示選「網頁應用程式」
3. 「說明」隨便填（例如「v1」）
4. 「執行身分」選：**我**
5. 「具有存取權的使用者」選：**所有人**（這是必要的，不然頁面沒辦法呼叫它；真正的保護是靠通關密語）
6. 點「部署」
7. 第一次部署 Google 會跳出「授權存取權」的畫面，選你自己的帳號 → 可能會出現「Google 尚未驗證這個應用程式」的警告，屬正常現象（因為是你自己寫的小工具，沒有送審），點「進階」→「前往（專案名稱）(不安全)」→ 允許
8. 完成後會顯示一個「網頁應用程式」網址，長得像：
   ```
   https://script.google.com/macros/s/AKfycb.../exec
   ```
   **把這個網址複製給 Claude**，接下來會幫你接進 `/review` 頁面的同步功能裡

## 之後如果要改程式碼

改完程式碼後，不能只按「儲存」，要重新「管理部署作業」→ 點編輯（鉛筆圖示）→ 版本選「新版本」→ 部署，網址通常不會變。

## 補充說明

- 試算表裡會自動出現兩個分頁：
  - 「項目清單」：原始待查證項目（分類、食材、待查證欄位、建議查證來源），貼上 VERIFICATION_TODO.md 內容解析後會自動上傳到這裡，所有裝置共用
  - 「查證紀錄」：目前的核對狀態（已核對、備註、最後更新時間），按「同步到試算表」時更新這裡；每個項目只會有一列，重複同步會覆寫同一列，不會產生重複資料
- 「項目 ID」欄位是拿來對應同一個項目用的，不用手動處理，也不要手動刪改這一欄，不然可能造成資料對不起來
- 密語只能防止「不知道密語的人／機器人」亂寫資料，防不了「打開這個網頁的人自己去翻瀏覽器開發者工具看密語」——因為這是純前端網頁，密語必然會出現在瀏覽器送出的網路請求裡。這個工具本來就只有你自己在用，這個程度的保護已經足夠；但不要把這個頁面的網址公開分享出去。
