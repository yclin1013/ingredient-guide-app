## 2026-08-12 — 查證清單工具再優化：查證來源可以直接點連結、同步按鈕隨時按得到

- 查證清單裡建議的查證來源（例如農糧署的產季查詢、食藥署的營養資料庫）現在可以直接點連結跳轉過去查，不用自己再開分頁搜尋

## 2026-08-11 — 查證清單工具改成跨裝置同步，隨時隨地查證進度都一致

- 做了一個可以用手機隨時核對食材資料的工具：把還沒查證完的食材欄位列成清單，查證完就打勾、寫下查到的資料
- 不管用哪一台裝置操作（手機、電腦），進度都會同步，不用擔心資料對不起來
- 打勾、寫備註這些動作就算沒有網路也能先存起來，等有網路再按一下同步，不會因為訊號不好就用不了
